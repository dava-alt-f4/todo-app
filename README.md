# toDo

A lightweight productivity application built for personal task management.

Inspired by modern task management applications while maintaining its own philosophy of simplicity, speed, and smart filtering.

> Currently under active development.

---

## Philosophy

The application is designed around three core principles:

- Frictionless task entry
- Lightweight user experience
- Smart filtering with a simple database structure

---

## Features (Planned)

- Dashboard
- Quick Task Input
- Categories
- Task Management
- Archive
- Interactive Calendar
- Smart Sorting

---

